01 / THE STARTING POINT

The problem behind the project.

A short quiz can check recognition, but it cannot show that someone can build, debug or retain an idea. This project turns a collection of learning material into a sequence of deliberate activities.

02 / PROJECT SCOPE

What this work explores.

The current version combines 38 roadmap modules, 152 evidence activities, nine project briefs and 36 foundation labs. Learners can run Python and SQL, inspect release simulations, plan study sessions and save reflections. It is a personal platform developed with AI-assisted implementation and browser-based verification.

03 / THE REASONING

Decisions worth explaining.

01

Different kinds of evidence

Foundation exercises use automatic checks. Larger assignments and project rubrics are explicitly self-assessed. The interface keeps those meanings separate.

02

Privacy by construction

The public build uses a file allowlist. Full source textbooks and personal contact records are excluded from the deployed files, rather than simply hidden in the interface.

03

Progress that belongs to a learner

Device profiles keep separate local records. Cloud account integration is prepared, with database access policies and conflict handling, but awaits an owner-configured backend.

04 / EVIDENCE & NEXT STEP

Where the project stands.

The live workspace is available to explore. Checks cover Python/SQL execution, profile separation, delayed recall, backup transfer and mobile layout. Browser SQL uses SQLite; production MySQL operations require an external lab. Cloud login is not yet activated.
